# java-lotto-precourse
### 기능 목록
1. 입력 기능
    - [x] 로또 구입 금액 입력
        - 금액이 양의 정수인지 검증
        - 1000으로 나누어 떨어지는지 검증
    - [x] 당첨 번호 입력 (번호는 쉼표(,)를 기준으로 구분)
        - 쉼표로 구분된 6개의 입력인지 검증
        - 각 번호가 1~45 사이 정수인지 검증
        - 중복된 번호가 없는지 검증
    - [x] 보너스 번호 입력
        - 1~45 사이의 정수인지 검증
        - 당첨 번호와 중복되지 않는지 검증
2. 출력 기능
    - [x] 발행한 로또 수량 및 번호 출력 (번호는 오름차순 정렬)
    - [x] 당첨 통계 출력 (등수별 개수, 상금 표시)
    - [x] 수익률 출력
    - [x] 에러 상황 시 에러 문구 출력 “[ERROR]”로 시작
3. 로또
    - [x] 구입 금액으로 구매 가능한 로또 개수 계산
    - [x] 반복할 횟수만큼 번호 추첨
    - [x] 당첨 번호와 비교해 몇 개가 일치했는지 확인
    - [x] 수익률 계산 (소수점 둘째 자리 반올림)
